⚠️ IMPORTANT: Session Context Mixing Issue

Problem: When you login with different users in the same browser (different tabs), the newer login overwrites the authentication context of the previous login.

Why: Browsers share cookies across tabs, so Spring Security uses the same session for all tabs.

Solutions:

  • 🔧 Use Different Browsers: Login as User in Chrome, Seller in Firefox
  • 🕵️ Use Incognito/Private Windows: Each private window has isolated cookies
  • 👤 Use Different Devices: Login from different computers/phones
  • 🧹 Clear Cookies: Clear browser data between different user logins
